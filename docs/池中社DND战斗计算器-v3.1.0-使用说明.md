# 池中社 DND 战斗计算器 v3.1.1 使用说明

池中社 DND 战斗计算器是一款中文离线工具，用于结算 D&D 5e 2014 规则下的一次攻击或法术伤害。普通攻击可以在快速计算页一键完成。偷袭、至圣斩、多目标豁免、伤害抗性等情况可以在高级工作台中处理。

## 下载安装

请在 [v3.1.1 发布页面](https://github.com/Kuacha031114/DND-calculator/releases/tag/v3.1.1) 下载与电脑对应的文件。

| 系统 | 下载文件 | 适用范围 |
| --- | --- | --- |
| Windows | `DND.v3.1.1.exe` | 64 位 Windows |
| macOS | `DND.v3.1.1-macOS.zip` | Apple Silicon 芯片的 Mac |

两个版本目前都没有商业代码签名。系统可能在首次启动时显示安全提醒。

### Windows 启动方法

1. 下载 `DND.v3.1.1.exe`。
2. 将文件放在自己有读写权限的位置，例如桌面或文档文件夹。
3. 双击运行。
4. 如果 Windows 显示来源未知提醒，请确认文件来自本仓库的发布页面，再按照系统提示选择继续运行。

程序配置保存在用户配置目录中，应用本体可以移动，不需要放在固定文件夹。

### macOS 启动方法

1. 下载并解压 `DND.v3.1.1-macOS.zip`。
2. 将应用拖入“应用程序”文件夹，或放在其他常用位置。
3. 首次启动时，在 Finder 中右键应用并选择“打开”。
4. 在系统确认窗口中再次选择“打开”。

如果双击后只看到安全提示，请使用右键打开。这个操作通常只需完成一次。

### 从源码启动

源码运行需要 Python 3.10 至 3.12，并且 Python 安装中需要包含 Tkinter。

```bash
python -m pip install -e .
python -m dnd_calculator
```

## 第一次打开

程序每次启动都会进入快速计算页。首次打开时会显示简短欢迎说明。

你可以选择“使用示例值试一次”，然后直接点击“立即结算”。默认示例已经填好以下数值。

| 项目 | 默认值 |
| --- | --- |
| 目标 AC | 15 |
| 命中加值 | 加 5 |
| 攻击次数 | 1 |
| 攻击状态 | 普通 |
| 重击下限 | 20 |
| 伤害 | 1d8 加 3 |

完成这次示例后，你会在右侧看到命中数、重击数和总伤害。欢迎说明关闭后不会在下次启动时自动出现，顶部的“使用帮助”随时可以再次打开说明区。

## 快速计算

快速计算适合普通武器攻击、法术攻击和不需要命中后选择附加效果的连续攻击。整个过程只有三步。

### 第一步填写目标

在“目标 AC”中填写目标的护甲等级。

攻击总值达到或超过 AC 时命中。自然 20 自动命中并造成重击，自然 1 自动未命中。

#### 目标 AC 未知

勾选“不知道 AC，手动指定命中”，然后填写命中次数和其中的重击次数。命中次数不能超过攻击次数，重击次数不能超过命中次数。

手动模式不投 d20，也不使用 AC、命中加值、优势、劣势和重击下限。如果使用减 5 加 10，请先在桌面投骰时计入命中减 5，再把最终命中次数填入程序。勾选减 5 加 10 后，程序会对手动指定的命中加上额外伤害。

结果明细会先列出重击，再列出普通命中和未命中。这些记录都有独立编号，可以继续用于偷袭、至圣斩和其他命中后附加伤害。

### 第二步填写本次攻击

#### 命中加值

填写角色进行攻击检定时加到 d20 上的总修正。例如熟练加值、属性调整值和武器加值合计为 7，就填写 `7`。

#### 攻击次数

填写本次要连续结算的攻击数量。每次攻击都会独立投掷 d20，并分别判断命中和重击。

#### 攻击状态

选择普通、优势或劣势。

普通攻击投一个 d20。优势投两个 d20 并采用较高结果。劣势投两个 d20 并采用较低结果。

如果同一次攻击同时具有优势和劣势，请在快速页选择普通。需要记录多个优势与劣势来源时，可以进入高级工作台，程序会自动完成抵消。

#### 重击下限

普通情况下填写 `20`。咒剑诅咒和勇士精通重击可以填写 `19`，勇士卓越重击可以填写 `18`。

自然 1 始终自动未命中，不会因为自定义重击范围变成重击。

#### 减 5 加 10

勾选后，本次所有攻击都会承受命中减 5，命中后的固定伤害增加 10。

快速页会把这个选项用于本次全部攻击。如果只有部分攻击使用神射手或巨武器大师，请到高级工作台逐次选择。

程序不会替你判断武器是否符合专长条件。武器资格、距离和其他使用限制仍由玩家与 DM 确认。

#### 伤害骰

三个输入框依次表示骰子数量、骰面和固定伤害。

例如长剑单手伤害 `1d8+3` 应填写 1、8、3。固定伤害允许填写负数。

重击会增加符合条件的伤害骰，不会把固定伤害翻倍。

### 第三步立即结算

点击“立即结算”后，程序会依次完成命中投掷和所有命中攻击的伤害投掷，不需要再点击第二个伤害按钮。

结果摘要会显示以下内容。

1. 命中数
2. 重击数
3. 总伤害

点击“查看每次投掷明细”可以查看每一次攻击的原始 d20、采用值、命中修正、命中状态、伤害骰和规则说明。

点击“再投一次”会使用当前设置重新投掷。任何输入发生变化后，旧结果都会显示“设置已改变”。再次点击“立即结算”即可生成新结果，不会混用修改前后的数据。

输入不合法时，提示会直接显示在对应输入框附近。修正数值后即可继续结算。

### 转到高级工作台继续编辑

点击“在高级模式继续编辑”后，程序会把当前快速设置转换为一个新的目标和一个新的攻击条目。

原有高级目标、条目和自定义预设不会被覆盖。进入高级工作台后，可以继续添加伤害类型、偷袭、至圣斩、抗性等规则。

## 高级工作台

高级工作台适合以下情况。

1. 多个目标分别进行豁免
2. 偷袭、至圣斩等命中后才决定的伤害
3. 只有部分攻击使用减 5 加 10
4. 伤害抗性、易伤、免疫和固定减伤
5. 精灵精准、半身人幸运和重武器战斗风格
6. 自动伤害与自定义预设

顶部流程条给出了固定顺序。

1. 选择目标
2. 配置攻击或法术
3. 投掷检定
4. 选择附加伤害
5. 查看最终结果

左侧负责配置，右侧负责投掷与查看结果。字段修改后会自动保存，不需要再执行“应用当前编辑”。

### 管理目标

点击“添加目标”可以建立新的目标。选择列表中的目标后，可以编辑名称和 AC。

“复制当前目标”会复制当前目标的全部防御设置，适合快速建立数值相同的多个敌人。“删除当前目标”会删除所选目标，请先确认相关攻击或法术是否仍需要使用它。

一个目标可以保存以下信息。

1. 名称和 AC
2. 力量、敏捷、体质、智力、感知和魅力豁免加值
3. 伤害抗性
4. 伤害易伤
5. 伤害免疫
6. 非魔法武器抗性
7. 重击免疫
8. 固定减伤

### 管理攻击或法术

每一行代表一组攻击、一个豁免法术或一次自动伤害。使用添加、复制、删除和排序按钮管理条目。

选择条目后，先选择结算模式。界面只会显示当前模式需要的字段。

| 模式 | 适用情况 | 结算方式 |
| --- | --- | --- |
| 攻击检定 | 武器攻击和法术攻击 | 逐次投 d20，命中后再投伤害 |
| 豁免检定 | 火球术等要求目标豁免的效果 | 每个目标独立豁免并结算伤害 |
| 自动伤害 | 魔法飞弹等不需要攻击或豁免的效果 | 跳过 d20，直接投掷伤害 |

### 攻击检定模式

填写攻击次数、命中加值、目标和主要伤害。目标 AC 来自所选目标。

如果目标 AC 未知，勾选“AC 未知，手动指定命中”，填写命中和重击次数。程序会为这些结果创建独立攻击记录，仍可在具体命中上选择偷袭和至圣斩。

右侧点击“① 投掷检定 / 结算法术”。程序会显示每次攻击的 d20 和命中状态，同时冻结本次攻击使用的规则设置。

如果条目包含偷袭、至圣斩等命中后附加伤害，请打开“② 命中后附加”，在具体命中上勾选要使用的效果。未命中的攻击不能选择附加伤害。

完成选择后，点击“③ 结算攻击伤害”。右侧会显示每次命中的伤害组成和最终总伤害。

如果没有需要选择的附加伤害，也需要点击“③ 结算攻击伤害”完成攻击伤害投掷。

### 豁免检定模式

填写豁免 DC、豁免属性、成功结果、伤害和目标。

成功结果可以选择全伤、半伤或无伤。点击“① 投掷检定 / 结算法术”后，每个目标都会使用自己的对应豁免加值独立投掷，并直接完成伤害结算。

结果会分别显示每个目标的原始骰、总值、成功状态、原始伤害和最终伤害。

### 自动伤害模式

自动伤害不会投 d20。填写伤害和目标后，点击“① 投掷检定 / 结算法术”即可直接结算。

同一目标承受三发魔法飞弹时，可以用 `3d4+3` 表示合计伤害。当前版本不负责把每一发飞弹分别分配给不同目标。如果需要不同目标承受不同发数，可以建立多个自动伤害条目。

## 高级选项

高级选项分为“攻击规则”“预设与附加伤害”“目标防御”三个页签。

### 攻击规则

#### 优势与劣势来源

分别填写优势来源数和劣势来源数。只要双方都存在，优势和劣势就会抵消为普通投掷。多个同类来源不会继续增加 d20 数量。

#### 精灵精准

启用后，符合条件的优势攻击会投三个 d20 并采用最高结果。程序只负责投骰，适用属性和其他资格由玩家确认。

#### 半身人幸运

启用后，攻击 d20 出现自然 1 时会重骰一次，并接受新结果。

#### 祝福术与灾祸术

祝福术会在攻击总值中加入正向 d4，灾祸术会加入负向 d4。两者可以同时记录，程序会分别投掷并计算。

#### 重武器战斗风格

适用的武器伤害骰出现 1 或 2 时重骰一次，并强制接受新结果。该规则不会作用于偷袭、至圣斩等非武器伤害骰。

#### 逐次使用减 5 加 10

可以选择全部攻击，也可以指定某几次攻击。选择会在投掷攻击时写入本次结算快照，不能在看到命中结果后补开加 10 伤害。

#### 武器骰与魔法伤害

“武器骰”决定重击和重武器战斗风格等规则如何处理该伤害组件。“魔法伤害”会影响目标的非魔法武器抗性判断。

### 预设与附加伤害

通用预设用于快速填写规则字段，所有参数仍可继续修改。

| 预设 | 主要作用 |
| --- | --- |
| 神射手 | 填入逐次减 5 加 10 选项 |
| 巨武器大师 | 填入逐次减 5 加 10 选项 |
| 重武器战斗风格 | 合格武器骰的 1 和 2 重骰一次 |
| 祝福术 | 攻击检定加入正向 d4 |
| 灾祸术 | 攻击检定加入负向 d4 |
| 精灵精准 | 优势时使用三个 d20 取高 |
| 半身人幸运 | 自然 1 重骰一次 |
| 咒剑诅咒 | 重击下限改为 19 |
| 勇士精通重击 | 重击下限改为 19 |
| 勇士卓越重击 | 重击下限改为 18 |
| 偷袭 | 每轮一次，命中后选择具体攻击 |
| 至圣斩 | 命中后选择一个或多个具体攻击 |
| 凶蛮攻击 | 重击时增加一颗合格武器骰 |
| 野蛮重击 | 重击时增加设定数量的武器骰 |

预设不会检查角色等级、武器类别、攻击距离、法术位、每轮次数和资源余量。应用预设后，请按照角色实际能力调整骰数和字段。

自定义预设会保存在 v3 配置中，可以在之后的结算中继续使用。

### 伤害组件与作用范围

每个伤害组件都可以设置名称、骰子、固定值、伤害类型、魔法性、重击行为和作用范围。

可用的作用范围包括以下四类。

1. 每次命中
2. 每轮一次并在命中后选择
3. 仅指定命中
4. 仅重击追加

偷袭通常使用“每轮一次并在命中后选择”。至圣斩通常使用“仅指定命中”。

### 目标防御

伤害类型包含 D&D 5e 的 13 种标准类型，也可以使用自定义类型。混合伤害会按类型分别处理。

免疫会使对应伤害归零。抗性通常使对应伤害减半并向下取整。易伤通常使对应伤害翻倍。同一份伤害同时遇到抗性和易伤时，两者抵消。

非魔法武器抗性只处理符合条件的非魔法武器伤害。重击免疫只取消额外重击骰，攻击本身仍然命中。固定减伤会按照引擎规定的顺序参与结算。

如果防御没有产生预期效果，请检查伤害组件的伤害类型、“武器骰”和“魔法伤害”设置是否与目标防御相符。

## 手动重骰

完成伤害投掷后，可以打开手动重骰页签，勾选具体骰子并应用重骰。

这是通用工具。新结果必须接受，同一颗骰子不能通过这个流程反复挑选结果。重武器战斗风格等自动规则会由引擎独立执行并记录。

## 实战示例

### 示例一　长剑连续攻击

目标 AC 为 15，角色命中加值为 5，每次伤害为 `1d8+3`，本回合攻击两次。

1. 留在快速计算页。
2. 填写目标 AC 15。
3. 填写命中加值 5 和攻击次数 2。
4. 选择普通。
5. 填写伤害 1d8 加 3。
6. 点击“立即结算”。

右侧会显示两次攻击中有几次命中、是否出现重击，以及所有命中造成的总伤害。

### 示例二　盗贼在命中后使用偷袭

假设主要武器伤害为 `1d8+4` 穿刺，偷袭伤害为 `3d6`。

1. 进入高级工作台并添加目标。
2. 添加攻击条目，选择攻击检定。
3. 填写命中加值、攻击次数和 `1d8+4` 穿刺伤害。
4. 在“预设与附加伤害”中添加偷袭，并把骰数调整为 3d6。
5. 点击“① 投掷检定 / 结算法术”。
6. 打开“② 命中后附加”，在一个命中上勾选偷袭。
7. 点击“③ 结算攻击伤害”。

如果选中的攻击是重击，符合条件的偷袭伤害骰会按照重击规则增加。

### 示例三　圣武士使用至圣斩

1. 在高级工作台建立攻击检定条目。
2. 在“预设与附加伤害”中添加至圣斩。
3. 按照实际法术位和目标类型填写至圣斩骰数。
4. 先投掷检定。
5. 在“② 命中后附加”中选择具体命中。
6. 点击“③ 结算攻击伤害”。

至圣斩可以在看到命中后决定是否使用。程序会把选择关联到具体攻击，不会让其他攻击继承这次选择。

### 示例四　火球术命中多个目标

假设火球术豁免 DC 为 15，伤害为 `8d6` 火焰，成功时伤害减半。

1. 为每个目标建立独立目标记录。
2. 分别填写目标的敏捷豁免加值和火焰抗性等防御。
3. 新建条目并选择豁免检定。
4. 选择敏捷豁免，填写 DC 15。
5. 选择成功半伤，填写 `8d6` 火焰伤害。
6. 选择全部需要结算的目标。
7. 点击“① 投掷检定 / 结算法术”。

结果区会按目标分别显示豁免投掷、成功状态、原始伤害、半伤处理和抗性处理后的最终伤害。

## 配置与数据

v3.1.0 会保存快速计算输入、高级目标、高级条目、自定义预设、窗口设置、首次提示和帮助区状态。

配置文件位于以下位置。

| 系统 | 配置路径 |
| --- | --- |
| Windows | `%APPDATA%/池中社/DND战斗计算器/config-v3.json` |
| macOS | `~/Library/Application Support/池中社 DND战斗计算器/config-v3.json` |
| Linux 源码运行 | `$XDG_CONFIG_HOME/chizhong-dnd-calculator/config-v3.json` |

保存时会先写入临时文件，再进行原子替换。配置损坏时，程序会恢复默认设置，并将原文件备份为带时间标记的 `config-v3.corrupt` 文件。

v3 不读取也不覆盖 v2 的 `calculator_config.json`。升级后需要重新配置，旧版文件仍可独立使用。

## 常见问题

### 为什么“③ 结算攻击伤害”无法点击

攻击检定需要先点击“① 投掷检定 / 结算法术”。完成命中投掷后，伤害按钮才会启用。

豁免检定和自动伤害会在第一个按钮中直接完成伤害结算，不需要使用第三个按钮。

### 为什么修改设置后结果变成过期

检定完成后，程序会保留当时使用的规则快照。修改目标、命中、伤害或规则后，旧结果会标记为过期，防止不同设置下的命中与伤害混在一起。使用当前设置重新投掷即可。

### 偷袭和至圣斩在哪里选择

先在高级工作台的“预设与附加伤害”中加入对应组件，再投掷攻击检定。出现命中后，到右侧“② 命中后附加”选择具体攻击。

### 什么时候可以选择全部目标

豁免检定和自动伤害可以同时作用于多个目标。攻击检定的每一组攻击会使用条目中指定的目标。

### 减 5 加 10 应该在哪里使用

如果本次所有攻击都使用，可以在快速计算页勾选。如果只对部分攻击使用，请在高级工作台中逐次指定。这个决定必须在投掷攻击前完成。

### 为什么抗性没有生效

请检查目标是否设置了正确伤害类型，同时检查伤害组件的类型、武器骰和魔法伤害标记。非魔法武器抗性不会处理已经标记为魔法伤害的组件。

### 为什么 macOS 不能直接打开

当前构建未签名，Gatekeeper 可能阻止首次双击启动。请在 Finder 中右键应用，选择“打开”，再确认一次。

### 为什么 v2 配置没有迁移

v3 使用新的数据结构和独立配置文件。为了避免错误解释旧字段，程序不会读取或覆盖 v2 配置。

## 规则基线与功能边界

程序以 D&D 5e 2014 规则为基线。

自然 1 自动未命中。自然 20 自动命中并造成重击。重击增加符合条件的伤害骰，固定伤害不会翻倍。抗性、易伤、免疫、豁免结果和舍入由规则引擎按既定顺序处理。

程序不会判断角色是否满足能力、专长、武器、距离、等级、法术位和资源条件。这些内容需要玩家与 DM 共同确认。

当前版本不包含以下功能。

1. D&D 5e 2024 规则切换
2. 角色卡和职业成长管理
3. 完整武器、法术、职业或怪物数据库
4. 生命值、先攻、状态持续时间和资源追踪
5. 命中概率、期望伤害和蒙特卡洛模拟
