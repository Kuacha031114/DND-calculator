# 池中社 DND 战斗计算器 v3.2.0

面向中文跑团社群的离线 D&D 5e 2014 攻击与伤害结算工具。v3 将规则引擎与 Tkinter 界面分离，可在 Windows 和 macOS 上运行。

## 下载与使用说明

- [下载当前稳定版 v3.1.1（Windows 与 macOS）](https://github.com/Kuacha031114/DND-calculator/releases/tag/v3.1.1)
- [阅读稳定版完整使用说明](docs/池中社DND战斗计算器-v3.1.0-使用说明.md)

第一次使用可以保留默认值，点击“立即结算”完成一次示例攻击。完整说明包含快速计算、高级工作台、偷袭、至圣斩、多目标豁免、配置位置和常见问题。

## 主要能力

- 三步式快速计算：填写 AC、攻击和伤害骰后，一键得到命中与总伤害
- AC 未知时可手动指定命中和重击次数，再使用同一引擎结算伤害
- 命中、重击、总伤害摘要，逐次投掷过程按需展开
- 首次使用提示、字段帮助和独立高级工作台
- 攻击检定、多个独立目标的豁免检定、自动命中伤害
- 普通/优势/劣势及相互抵消、精灵精准、半身人幸运
- 自然 1/20、19–20 与 18–20 扩展重击、重击免疫
- 每次命中、命中后选择、每轮一次和仅重击追加的伤害组件
- 偷袭、至圣斩、巨武器大师、神射手、重武器战斗风格等通用预设
- 13 种标准伤害类型、魔法/非魔法抗性、易伤、免疫和固定减伤
- 单颗骰子手动重骰；规则型重骰只执行一次并接受新结果
- 高级工作台可动态添加多个命中修正骰，以及不同伤害类型、作用范围和重击规则的多个伤害组件
- 构筑命中率、重击率与期望伤害比较，支持优势、劣势、精灵精准和减 5 加 10
- DM 战斗时长规划：汇总队伍 DPR，按怪物 AC、数量、HP、抗性与输出在线率估算轮数
- 新版用户目录配置、原子保存和损坏配置备份
- 桌面与网页均提供快速计算、高级工作台、强度与时长、跨端配置导入导出和完整结算明细

预设不会判断角色等级、武器资格、距离、法术位或其他资源是否可用，这些条件由玩家和 DM 确认。

## 启动源码

需要 Python 3.10–3.12，并确保 Python 安装包含 Tkinter。

```bash
python -m pip install -e .
python -m dnd_calculator
```

运行测试：

```bash
python -m unittest discover -s tests -v
```

## 网页离线版

网页版本使用 React、Pyodide 和同一套 Python 规则引擎，不上传配置或投骰结果。首次访问需要联网加载运行时，成功加载后可安装为 PWA 并离线使用。

- 计划部署地址：<https://kuacha031114.github.io/DND-calculator/>
- 快速计算、高级工作台和强度与时长均支持手机和桌面浏览器。
- “强度与时长”页面无需投骰，可用于玩家构筑比较、DM 审卡和遭遇 HP 规划。
- 网页配置保存在浏览器中，可与桌面版 `config-v3.json` 双向导入导出。

本地构建需要 Python 3.10 以上、Node.js 22 和 pnpm 11：

```bash
python -m build --wheel --outdir dist-web
cd web
pnpm install --frozen-lockfile
pnpm prepare-runtime
pnpm test
pnpm build
```

## 快速计算

程序启动后默认进入快速计算：

1. 填写目标 AC。
2. 填写命中加值、攻击次数、普通/优势/劣势、重击范围和伤害骰。
3. 点击“立即结算”，同时得到命中、重击和总伤害。

页面预填 AC 15、命中 +5、一次攻击和 1d8+3，可直接点击体验。“查看每次投掷明细”会展示所有 d20、修正和伤害骰。

## 高级工作台

偷袭、至圣斩、多目标、豁免法术、伤害抗性和自定义预设继续使用高级工作台：

1. 配置一个或多个目标。
2. 添加攻击、豁免或自动伤害条目；字段修改会自动保存。
3. 投掷检定，按具体命中选择附加伤害，再结算伤害。
4. 如需通用手动重骰，在结果下方选择单颗骰子并接受新结果。

快速页的“在高级模式继续编辑”会新增目标和攻击条目，不会覆盖已有高级配置。

高级工作台左侧按“选择目标 → 配置攻击或法术 → 编辑当前内容”排列。选择攻击检定、豁免检定或自动伤害后，只显示该模式需要填写的字段。高级选项进一步分为攻击规则、预设与附加伤害、目标防御三个页签；右侧结算区会提示当前应该投掷检定、选择附加伤害还是查看最终结果。

命中修正骰可以设为每次攻击自动加入，也可以在基础 d20 投出后选择一次攻击使用。伤害统一由可增删、复制和排序的组件组成，可分别设置骰子、固定值、伤害类型、是否属于武器骰、是否为魔法伤害、重击是否翻倍，以及每次命中、选择一次、选择多个或仅重击等作用范围。

输入一旦在检定后改变，旧结果会被标记为过期，必须重新投掷，避免把不同设置下的命中和伤害混在一起。

## 命中率、期望伤害与战斗时长

桌面端和网页端的“强度与时长”页面都使用共享 Python 分析引擎，用于投骰前的构筑与遭遇规划：

1. 设定共同的假想目标 AC。
2. 为每名角色建立一个构筑方案，填写命中加值、每轮攻击次数、投骰方式、重击范围和伤害骰。
3. 如有偷袭等每轮一次伤害，填写“首次命中附伤”；如有自动命中或已经单独算好的来源，填写“每轮固定伤害”。
4. 勾选需要“计入 DM 队伍”的方案，页面会汇总原始 DPR；未勾选的备选构筑仍显示比较结果，但不会被误算成另一名队员。
5. DM 填写怪物数量、每只 HP、输出在线率和伤害倍率，查看预计战斗轮数，并反推目标轮数对应的 HP 或怪物数量。

命中率使用完整 d20 离散分布计算，包含自然 1、自动命中的重击、普通/优势/劣势和三骰取高。重击默认翻倍伤害骰而不翻倍固定加值；“重击额外骰”用于凶蛮攻击等额外武器骰。所有分析方案会随网页配置一起保存在本机，并支持导入导出。

预计轮数是“怪物总 HP ÷ 有效队伍 DPR”的备团基线。输出在线率用于近似移动、控制、倒地和无法集火造成的损失；伤害倍率可近似普遍抗性或易伤。它不计算怪物输出、治疗、范围伤害、召唤物、传奇动作、击杀溢出或团灭概率，因此不能代替遭遇难度审核。

## 配置位置

v3 不读取也不覆盖 v2 的 `calculator_config.json`。v3.2 会自动把旧的 v3 配置迁移为配置格式 v2；新版导出的配置不能交给 v3.1.1 使用。

- Windows：`%APPDATA%/池中社/DND战斗计算器/config-v3.json`
- macOS：`~/Library/Application Support/池中社 DND战斗计算器/config-v3.json`
- Linux：`$XDG_CONFIG_HOME/chizhong-dnd-calculator/config-v3.json`

配置损坏时，程序会将原文件改名为 `config-v3.corrupt-时间.json`，恢复默认设置并显示警告。

桌面版会在字段修改后 500ms 防抖原子保存，关闭窗口前还会强制保存一次。跨端导入会先完整校验，再要求确认；确认后创建 `config-v3.before-import-时间.json` 备份并完整替换当前配置，不执行合并。网页版使用同样的完整替换语义，并在浏览器本地创建带时间戳的导入前备份；当前会话还可点击“撤销本次导入”。跨端导出会去除桌面窗口尺寸，同时保留分析方案、动态命中/伤害列表和未知扩展字段。

## 构建桌面程序

```bash
python -m pip install -e ".[build]"
pyinstaller --clean --noconfirm dnd_calculator.spec
```

GitHub Actions 会使用 Python 3.11 分别生成 Windows exe 和 macOS app。自动构建产物未签名；macOS 首次运行可能触发 Gatekeeper，可在 Finder 中右键应用选择“打开”。正式公开分发前应配置开发者签名和 Apple 公证。

macOS 不要使用 `/usr/bin/python3` 打包。系统 Python 3.9 搭载的 Tk 8.5 在新版本 macOS 上可能只显示空白窗口；构建脚本会拒绝 Tk 低于 8.6 的环境。推荐使用 Python 3.11 和 Tk 8.6 或更高版本。

## 规则边界

规则基线为 D&D 5e 2014。程序提供攻击/法术数值结算、构筑期望值比较与战斗时长基线规划，但不提供：

- 2024 规则切换
- 角色卡、职业等级或完整规则资料库
- 怪物数据库、生命值、先攻、状态持续时间和资源追踪
- 蒙特卡洛模拟、遭遇难度或团灭概率评级

咒剑诅咒和勇士精通重击预设为 19–20；勇士卓越重击为 18–20。自然 1 始终自动未命中，不能因自定义重击范围成为重击。
