# 池中社 DND 战斗计算器 v2.0 使用说明

---

## 界面概览

程序分为左右两栏：
- **左侧 ⚔ 命中投掷**：掷 d20 判断是否命中，需先于伤害投掷执行
- **右侧 🔥 伤害投掷**：根据命中结果计算伤害，支持交互式重骰

程序关闭时会**自动保存**所有设置，下次启动后自动恢复。

---

## 左侧：命中投掷

### 基础加值

| 字段 | 说明 |
|------|------|
| 熟练加值 | 角色的熟练加值（通常 +2 到 +6） |
| 属性调整值 | 攻击所用属性的调整值（可为负数） |
| 额外加值 | 其他来源的命中加值，如魔法武器 |
| 攻击次数 | 本轮攻击总次数 |

### 目标护甲等级 AC

- 填入敌方 AC 后，投掷结果会**自动判定命中/未命中**，并将命中次数回填到右侧
- 设为 **0** 则跳过命中判定，所有攻击均视为命中

### 攻击方式

- **普通**：投一次 d20
- **优势**：投两次取较大值
- **劣势**：投两次取较小值

### 重击触发范围

- 默认 **20**（标准规则）
- 勇士战士可改为 **19**，咒剑术士可改为 **18**
- 触发重击后，伤害骰子数量自动翻倍

### -5/+10 专长

勾选后：命中骰 **-5**，伤害 **+10**（适用于「神射手」「重武器精通」专长）。
此开关同时作用于左侧命中和右侧伤害，无需分别设置。

### 额外命中加值骰子

用于投掷附加在命中检定上的骰子（较少用到，一般留空）。
每行左侧的**勾选框**控制该行是否参与计算，取消勾选即临时禁用。

---

## 右侧：伤害投掷

> ⚠️ **必须先完成命中投掷，右侧的「进行伤害投掷」按钮才会启用。**

### 动作伤害 / 附赠动作伤害

两个标签页结构相同：

| 字段 | 说明 |
|------|------|
| 伤害加值 | 属性调整值、魔法武器加值等固定伤害加值 |
| 命中次数 | 本次实际命中的次数（命中投掷后自动填入，可手动修改） |
| 伤害骰子 | 每次命中所投掷的骰子，最多 6 组，支持自定义名称 |

每行骰子左侧的**勾选框**控制该行是否参与计算。

### 骰子类型说明

`d4` `d6` `d8` `d10` `d12` `d20` `d100`  
格式为「颗数 × 骰型」，例如武器伤害 2d6 = 类型选 d6，数量填 2。

---

## 伤害结果区：交互式重骰

完成伤害投掷后，每颗骰子的点数以**可点击按钮**显示。

### 手动选中重骰

1. **点击**任意骰子数字按钮，按钮变红 = 选中
2. 再次点击取消选中
3. 点击「**🎲 重骰选中**」，所有选中骰子重新投掷

### 快速重骰低值骰子

右侧「**快速重骰：点数 ≤ N → 🎲 重骰**」：

- 将所有点数 ≤ N 的骰子一键重骰
- 默认 N = **2**，对应「重武器精通」战斗风格（重投 1 和 2）
- 改为 N = **1** 仅重投 1

> 注意：根据 5e 规则，重骰后必须使用新结果，即使新结果更低。

### 清除选择

点击「**清除选择**」取消所有选中状态，不触发重骰。

## 典型战斗流程示例

**场景**：战士用+1长剑攻击，2次攻击，目标 AC 15

1. **左侧填写**：熟练加值 4，属性调整值 3，额外加值 1，攻击次数 2，AC 填 15
2. **骰子行**：留空（长剑命中无附加骰）
3. 点击「**🎲 进行命中投掷**」→ 假设命中 1 次，右侧命中次数自动填为 1
4. **右侧动作伤害**：伤害加值填 4（属性3+武器1），骰子行填「长剑 d8 ×1」
5. 点击「**🎲 进行伤害投掷**」→ 查看伤害结果
6. 若投出 1 点，点击该骰子按钮选中后点「🎲 重骰选中」（或直接用快速重骰 ≤1）

## 常见问题

**Q：伤害投掷按钮是灰色的？**  
A：需先点击左侧「进行命中投掷」按钮，右侧才会解锁。

**Q：命中次数没有自动填入？**  
A：请确认左侧 AC 不为 0。AC = 0 时程序不判定命中，不会回填次数。

**Q：重击了但骰子没有翻倍？**  
A：重击骰子翻倍发生在**伤害投掷**阶段，命中结果里的★标记会传递到伤害计算，届时对应那次命中的骰子数量会自动翻倍。

**Q：配置文件在哪里？**  
A：与程序 exe 同目录下的 `calculator_config.json`，可手动删除以恢复默认设置。
